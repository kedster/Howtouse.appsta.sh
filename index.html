Getting Started with appsta.sh

1

Installation

Install appsta.sh using your preferred package manager:

curl -fsSL https://appsta.sh/install.sh | bash

Or if you prefer npm:

npm install -g appsta
2

Initialize Your Project

Create a new project with appsta.sh:

appsta init my-awesome-app
cd my-awesome-app
3

Configure Your App

Customize your app settings in the appsta.config.json file:

{
  "name": "my-awesome-app",
  "version": "1.0.0",
  "framework": "react",
  "deploy": "auto"
}
4

Start Development

Run your development server:

appsta dev

Your app will be available at http://localhost:3000
